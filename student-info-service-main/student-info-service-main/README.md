**Student Info Service**
The **Student Info Service** is a core microservice within the **SchoolHub ERP Platform**, responsible for managing all student‑related master data. It provides RESTful APIs for storing, retrieving, and updating student profiles, contact information, guardians, addresses, enrollments, and student profile snapshots.

This service is built using **Java Spring Boot**, follows a clean layered architecture, and integrates with **MySQL / Amazon Aurora MySQL** for persistent storage.

**Features**
- Manage student master records  
- Store and retrieve student contact information  
- Maintain guardian details  
- Track student addresses  
- Manage academic enrollments  
- Store analytics‑ready student profile snapshots  
- RESTful API endpoints for all CRUD operations  
- JPA/Hibernate ORM with repository abstraction  
- Cloud‑ready architecture for AWS deployment
